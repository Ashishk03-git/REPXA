# REPXA – Repair Management System

REPXA is a web-based Repair Management System designed to help electronics repair shops manage their daily repair operations digitally.

## Features

- Owner and Staff Login
- Role-Based Access Control
- Customer Management
- Repair Request Management
- Repair Status Tracking
- Staff Management
- Technician Assignment
- Inventory Management
- Billing and Invoice Management
- Customer Repair History
- Recycle Bin
- Database Backup
- Profile and Shop Management

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Project Purpose

REPXA helps replace manual repair-shop processes with a centralized digital system for managing customers, repairs, staff, inventory and billing.

## Local Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into:

   `C:\xampp\htdocs\REPXA`

4. Create a MySQL database named:

   `repxa_db`

5. Import the required database tables/data.
6. Open:

   `http://localhost/REPXA/`
